# Data dictionary

This file describes the compact **observed/public evidence layer** under `data/public/` plus the Transpower connection-pipeline table under `data/pipeline/`.  Scenario-model outputs are documented in the main `README.md` and generally live under source-specific `model/` directories or `data/model/`.

The public layer is generated by `build_public_views.py` from normalized, checked-in source data.  It is intentionally simpler than the modelling layer and is suitable for dashboards, exploratory charts and external reuse.

## `data/public/generation_mix_daily.csv`

Daily observed generation aggregated from Electricity Authority `Generation_MD` files into simplified fuel groups.

Fields:

- `date`: trading date.
- `fuel`: simplified fuel group such as Hydro, Geothermal, Wind, Solar, Coal or Gas.
- `generation_mwh`: daily observed generation in MWh.

The underlying generation archive begins in August 1997.  Fuel grouping is a presentation classification performed by `build_public_views.py`; ambiguous industrial cogeneration is not automatically classified as renewable.

## `data/public/renewable_share_daily.csv`

Daily observed generation and renewable share derived from `generation_mix_daily.csv`.

Fields:

- `date`
- `total_generation_mwh`
- `renewable_generation_mwh`
- `renewable_pct`

Renewable classification includes hydro, geothermal, wind, solar and clearly identified biomass/biogas.  This is an observed-generation share, not a lifecycle-emissions measure.

## `data/public/demand_daily.csv`

Daily MWh from Electricity Authority `Grid_export`, normalized by `normalize_wholesale.py`.

This is a grid-export measure and is **not** a direct estimate of gross behind-the-meter electricity consumption.  The modelling layer separately estimates retained behind-the-meter solar where required.

## `data/public/hydro_storage_daily.csv`

National daily sums across the curated major-lake HMD storage series.

Fields:

- `active_storage_mm3`
- `contingent_storage_mm3`
- `total_usable_storage_mm3`

Units are million cubic metres (Mm³).  These HMD reservoir-volume quantities are **not interchangeable** with System Operator / Transpower controlled-storage GWh figures.  Any energy-equivalent conversion used elsewhere in the repository is a separate derived calculation with its own assumptions.

## `data/public/solar_installations_monthly.csv`

Compact national distributed-solar history assembled from the current normalized Electricity Authority distributed-generation tables.

Fields include:

- `month_end`
- `all_solar_icps`
- `all_solar_installed_capacity_mw`
- `new_solar_installations`
- `residential_solar_icps`
- `residential_solar_installed_capacity_mw`
- `solar_plus_battery_icps`
- `solar_plus_battery_registered_capacity_mw`
- `battery_attachment_share_of_solar_pct`
- `category_reliability`

The explicit EA `Solar (with battery)` category is the preferred battery observation.  Registry category history before November 2023 should be treated cautiously because category changes are not reliably backdated.  Registered solar-with-battery generation capacity is useful as a connection-power proxy but is not battery-only power and is not storage-energy capacity in kWh/MWh.

## `data/public/wholesale_prices_daily.csv`

Daily average final energy prices at three reference nodes:

- Otahuhu (`OTA2201`)
- Haywards (`HAY2201`)
- Benmore (`BEN2201`)

Fields contain each node's daily average NZD/MWh and `reference_mean_nzd_mwh`, the simple mean of the available reference-node averages.

This is **not** a demand-weighted national settlement price.  It is a compact public indicator intended for comparison and exploratory visualisation.

Monthly finalized price data are cached under `data/prices/monthly/`.  For the current unfinalized month, `update_prices.py` uses the Electricity Authority's daily files and ETags, reusing existing output rows when the source ETag is unchanged.

## `data/public/renewables_vs_price_daily.csv`

Date-aligned `renewable_pct` and `reference_mean_nzd_mwh` for exploratory comparison.

Correlation in this table is descriptive, not causal.  Electricity prices are affected by demand, hydrology, fuel availability, outages, transmission constraints, bidding behaviour and many other variables.

## `data/public/manifest.json`

Machine-readable list of public CSVs and their upstream normalized inputs.  The manifest explicitly marks this directory as observed/public derivatives rather than scenario-model results.

## `data/pipeline/transpower_generation_storage_pipeline.csv`

Normalized current Transpower generation and energy-storage **connection pipeline**.

The source workbook is retained at:

`data/pipeline/generation_and_energy_storage_connection_pipeline.xlsx`

Source provenance is recorded in:

`data/metadata/connection_pipeline_source.json`

This is a Transpower connection/delivery pipeline and is not identical to the Electricity Authority's broader generation investment-pipeline dashboard.  Project inclusion and status definitions therefore should not be mixed without checking the source definitions.

The connection pipeline changes relatively slowly and is checked by the weekly reference-data workflow rather than every day.

## Source and build relationships

```text
EA Generation_MD ----------------------> normalize_wholesale.py ---> generation_mix_daily.csv
                                                               \--> renewable_share_daily.csv

EA Grid_export ------------------------> normalize_wholesale.py ---> demand_daily.csv
EA HMD storage ------------------------> normalize_hydro.py -------> hydro_storage_daily.csv
EA distributed generation ------------> normalize_distributed_generation.py
                                                               \--> solar_installations_monthly.csv
EA final energy prices ----------------> update_prices.py --------> wholesale_prices_daily.csv
renewable_share + wholesale prices -------------------------------> renewables_vs_price_daily.csv

Transpower connection workbook --------> update_connection_pipeline.py
                                                               \--> transpower_generation_storage_pipeline.csv
```

For source URLs, local-copy policy, update cadence and modelling context, see `README.md` and `data/source_registry.csv`.
